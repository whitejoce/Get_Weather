# Querying Weather Skill

## 目标
使用 `scripts/GetWeather.py` 获取天气数据，由 **AI 自行组织解读**（工具的 `解读` 字段仅作参考）。

## 执行步骤
1. **确定目标城市**：用户指定城市则传 `--city-name <城市名>`；未指定则不传（自动 IP 定位）。
2. **调用脚本**（在 `scripts/` 目录下执行）：
   - `python GetWeather.py --city-name <城市名> --json` —— **推荐**。输出清洗后的结构化 JSON（中文键）。
   - `python GetWeather.py --city-name <城市名> --raw` —— 输出原始接口 JSON（`dataSK/dataZS/alarmDZ/fc/fc40`），需要完整细节（如 40 天日历、全部预警字段）时用。
   - `python GetWeather.py --city-name <城市名>` —— 人类可读文本（无 AI 时直接展示）。
3. **AI 解读**：基于 JSON 数据自行总结，建议覆盖：
   - 天气状况（今日白天/夜晚）、当前温度、今日温度区间、与昨日实测的对比（`昨日` 字段为近 5 天实测，可能缺失）
   - 湿度、风力、空气质量（AQI + 等级）
   - 简洁的当日要点与未来五日趋势（`五日预报`）
   - 有 `短临降水` 时优先引用其 `摘要`（"约 X 分钟后开始降雨/正在下雨"比生活指数的静态雨伞建议更精准，适合做出行提醒）
   - 有 `预警` 时**必须**醒目提示，并附详情链接
   - 按需引用 `生活指数`（约 30 项：雨伞/穿衣/紫外线/感冒等）
   - `解读` 字段是工具按固定句式合成的参考句，可引用、改写或忽略
4. **输出说明**：进度/定位信息走 **stderr**，stdout 只有 JSON（或文本），可直接 `json.load` 解析。

## 非交互约定
- 用户未指定城市时默认查“当前位置天气”（脚本自动 IP 定位），不要询问“是否允许定位”或“当前位置是什么”。
- 需要展示给用户时，先解析 JSON 再按响应风格整理，不要把整段 JSON 原样返回。
- 失败时返回简洁错误原因（网络失败、城市未找到等），并给出一次可执行的重试建议。

## 响应风格
- 先给结论（当前天气核心信息），再补充细节；不展示冗长原始日志。

## 数据源（自动选择）
- **官方 API 模式（推荐）**：检测到 API Key（环境变量 `WEATHERCN_API_KEY`/`API_KEY`，或脚本目录/当前目录 `.env` 中的 `API_KEY=`）时，`--json`/`--raw` 自动改走华风爱科开放平台（中国气象局华风×AccuWeather，openapi.weathercn.com）。每次查询 7 个轻量 JSON，额外提供：
  - 官方原生摘要（`解读`，自带"比昨天"对比）
  - 实况扩展：体感温度、紫外线（数值+等级文本）、阵风、气压趋势、**过去 24 小时温度（最高/最低）与累计降水 mm**、MEP 空气质量（含 PM10/臭氧；等级与首要污染物见 `今日.空气质量预报`）
  - 今日/五日：白天与夜晚各自的降水概率与风向风速、日出日落、月出月落/月相、日照时数、空气质量预报
  - 逐小时（12h）：气温+体感温度+降水概率+昼夜标识
  - 结构化预警：区域/等级/摘要/来源/官方详情链接
  - **分钟级短临降水**（`短临降水` 字段：`摘要`优先为官方原句 `官方描述`，如"20分钟后开始下小雨，下下停停"/"附近有降水，出门建议带伞"；附 `强度序列`（`步长分钟` 实测 6）、`开始钟点`/`渐止钟点` 绝对时间、`附近降雨.距离km`（本地点无雨但附近有回波）；`窗口末端仍有降雨=true` 表示数据窗口尽头仍在下雨、无法断言渐止，不要向用户转述"X分钟后停"；仅中国区域，接口失败时该字段不出现，与"无雨"区分）
  - JSON 的 `数据源` 字段会标记来源。
- **文本模式（无 --json）**：主数据仍来自天气网；有 Key 时额外叠加官方短临——雨具建议自动改为"未来两小时是否降水"（如"约25分钟后有雨，建议带伞"），有雨时展示强度条。短临失败/非中国区域时静默回退 dataZS 静态指数。
- **网页模式（回退）**：无 Key 或官方 API 失败时，自动回退到中国天气网抓取方案（零配置开箱即用）。`--city-code` 传的是天气网城市代码，官方 API 无法直接使用，脚本会提示并走网页数据源。
- 配额：标准测试 Key 每日 500 次（5 QPS），JSON 模式每次查询消耗 7 次；文本模式叠加短临时另需 2 次（translate+短临）。

## 数据源差异说明（重要）
输出首字段 `数据源` 标记本次来源，两套观测体系对同一时刻可能给出**不同表述甚至不同现象**（如"雨 vs 小雨"、"雾 vs 阴"），属正常现象：
- **官方 API**（AccuWeather 系）：天气词较粗（如"雨"），含日出日落/逐小时/今昨对比摘要
- **网页模式**（天气网 d1）：天气词较细（如"小雨"）
- 同一次回答内**不要混用两个来源的字段**，以当前输出的 `数据源` 为准
- 若与早前查询结果不一致，优先检查 `数据源` 是否切换，不要断言数据错了
- 需要跨源对比时，向用户明确说明两源体系差异

## 数据来源
中国天气网公开数据（自动定位 wgeo / 城市搜索 toy1 / 实况预报 d1.weather.com.cn）或华风爱科官方 API；接口字段说明见仓库 `test/README.md`。
